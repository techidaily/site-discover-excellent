The launch of our redesigned [DEX 3 DJ software](https://tools.techidaily.com/pcdj/products/) introduced [many new features](https://tools.techidaily.com/pcdj/products/) and some tweaks to base features as well. We found that the Denon DN-MC6000 script file required a patch to make better use of the [DJ controllers](https://tools.techidaily.com/pcdj/products/). capabilities.

The [Denon DN-MC6000 DJ controller](http://denondj.com/products/view/dn-mc6000#.VDf2Q%5FldW3k) is a popular choice among Mobile DJs due to it’s robust feature set including 4 channel support, the ability to control video mixing in DEX 3 and optional rack ears for 19″ rack mount rigs. It’s likely one of the most used DJ controllers throughout the PCDJ user base. They’ve recently released the MKII model, which we should have in soon to create a custom DEX 3 map for.
